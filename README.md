# RetroHub Test

Telegram Mini App game hub for nostalgic casual games.

## Local secrets

1. Copy `.env.example` to `.env`.
2. Set `TELEGRAM_BOT_TOKEN` to the token for `@GameCenterMini_bot`.
3. Never commit, paste into chat, or expose the `.env` file.

The test Mini App URL is planned as `https://test.workline.ink`.
